# 🧠 SecondBrain

SecondBrain is a full-stack web application designed for storing, organizing, and managing personal information efficiently. Built with React, TypeScript, FastAPI, and MongoDB Atlas, it provides a modern and scalable architecture for user authentication and data management.

---

## 📌 Overview

SecondBrain serves as a centralized platform where users can securely manage their information through an intuitive interface.

The project follows a full-stack architecture with:

* React + TypeScript frontend
* FastAPI backend
* MongoDB Atlas database
* RESTful API communication

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/mujeebmasi/SecondBrain.git

cd SecondBrain
```

---

### Backend Setup

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```

Backend runs on:

```text
http://localhost:8000
```

---

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```
